# Marine Condition Analysis and Classification Using Data Mining

[![Research Paper DOI](https://zenodo.org)](https://doi.org)
[![Orange Workflow DOI](https://zenodo.org)](https://doi.org)
[![License: MIT](https://shields.io)](https://opensource.org)

An empirical investigation of in-situ meteorological buoy observations from the NOAA National Data Buoy Center (Northwest Atlantic Ocean and Gulf of Mexico) modeled using the **CRISP-DM framework** in **Orange Data Mining**.

## 📄 Associated Research Paper
* **Title:** Marine Condition Analysis and Classification Using Data Mining
* **Authors:** Abhinav Bhatra (Researcher), Abhilasha Deshwar (Supervisor)
* **Published:** October 22, 2026 (Version v1)
* **Zenodo Paper DOI:** [10.5281/zenodo.23571040](https://doi.org)

## 📂 Repository Contents
* `workflows/` — Orange Data Mining workflow files (`.ows`)
* `data/` — Processed meteorological buoy observations and datasets
* `images/` — Workflow canvas diagrams, evaluation charts, and classification plots
* `Orange_Steps.md` — Step-by-step documentation of the Orange widget pipeline
* `DECISIONS.md` — Methodology and preprocessing design decisions
* `Demo_Script.md` — Walkthrough and demonstration guide
* `Presentation.pptx` — Project presentation slides

## 🚀 How to Run the Workflow
1. Download and install [Orange Data Mining](https://orangedatamining.com).
2. Clone or download this repository to your computer.
3. Open Orange and go to **File > Open**, then select the `.ows` workflow file inside the `workflows/` folder.
4. Verify that the **File** widget points to the dataset in the `data/` folder.
